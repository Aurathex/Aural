# Aural

Local-first voice dictation for Windows. Hold a hotkey, speak, release — your words are
transcribed **on your own machine** and typed into whatever app has focus.

> Status: early development (milestone M0). Nothing to install yet.

- No account, no telemetry, no cloud audio.
- Speech models are downloaded on demand from Settings, never bundled.
- English only for v1.

Design spec: [docs/superpowers/specs/2026-09-25-aural-design.md](docs/superpowers/specs/2026-09-25-aural-design.md)
