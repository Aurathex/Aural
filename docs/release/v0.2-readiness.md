## Needs you (manual)

1. **Dictate into the microphone** with a graphics-card option selected (e.g. Parakeet on the
   graphics card, or Whisper turbo if downloaded), and once on the processor.
2. **Hotkey tests** that need an unlocked desktop: run `cargo test -p aural-platform -- --ignored`
   while signed in and not locked (they passed in v0.1 validation).
3. **CI on GitHub**: the first real run confirms the Vulkan SDK silent install on the runner.
4. **Optional:** the 30 personal dictation clips (a check on real dictation, not a gate).

## Known limitations

- **AMD graphics cards** are untested (no hardware). The code paths are the same as NVIDIA's
  (DirectML, Vulkan) and failures fall back to the processor with a notice.
- **Estimates vs other hardware**: the ±35% check used this PC for both references and
  measurements; accuracy on very different PCs is unproven. Measurements always replace
  estimates once a model is downloaded.
- **DirectML on this PC is slower than the processor** for Parakeet (≈0.7 s vs 0.4 s); the
  labels reflect that, so it's not recommended here.
- **Large Whisper models on the processor** take 13–15 s per sentence and are labelled
  "too slow"; they need a graphics card.
- **transcribe-rs is vendored** (0.3.11 + one patch for the DirectML device); re-apply the patch
  when upgrading it (`third_party/transcribe-rs/AURAL-PATCH.md`).
- **Cancelling a check** can't interrupt a model that is in the middle of loading (up to
  ~3 min for a slow model); it stops right after.
- **Unsigned installer**: Windows SmartScreen will warn on first run (documented).
- The background check logic (job runner, cancel, automatic fallback wiring) is covered by
  the end-to-end runs above, not by automated tests.
