# Aural v0.3 — manual AMD validation checklist

Target PC: **the AMD test PC** — AMD Ryzen 7 9800X3D (with AMD Radeon built-in graphics, 512 MB),
**AMD Radeon RX 9070 XT 16 GB** (driver 32.0.31041.1004), 31 GB RAM, Windows 11 Home.

Artifact: `Aural_0.3.0_x64-setup.exe` — path, SHA-256 and commit in
`docs/release/v0.3-readiness.md`. Aural is not installed on that PC yet.

Write down for each step: pass/fail, what the app showed, and any numbers asked for. A
screenshot of each Models-page "Technical details" is the easiest record.

## 0. Install

1. Copy the installer to the AMD PC yourself (USB stick, your own share, etc.).
2. Check it: `Get-FileHash .\Aural_0.3.0_x64-setup.exe -Algorithm SHA256` must equal the
   SHA-256 in the readiness report.
3. Run it. SmartScreen will warn (unsigned): **More info → Run anyway**. It installs for
   your user only, no admin prompt.

## 1. Hardware detection

1. Aural opens on **Models**. Read the line describing this PC.
   - Expected: processor "AMD Ryzen 7 9800X3D", about 31 GB memory, graphics card
     "AMD Radeon RX 9070 XT" with about 16 GB.
   - The Radeon built-in graphics must **not** be presented as the graphics card.
2. Press **Check my PC** and allow the ~75 MB test-model download. Expected: finishes in a
   few minutes; every model gets a plain-language label.
3. Record the labels on: Parakeet v2, Parakeet v3, Whisper large-v3 turbo, Whisper small,
   Moonshine Streaming small (Recommended / Most accurate / Fastest / Live text / Won't
   work well + reason).

## 2. AMD graphics card (GPU) model selection

Parakeet uses DirectML, Whisper uses Vulkan. Both must run on the **RX 9070 XT**.

1. Download **Parakeet TDT 0.6B v2**. Under it choose the **graphics card** option.
   - General/sidebar status must reach "Ready".
   - Technical details → backend should read `directml:` followed by the RX 9070 XT's
     name. `directml:` with the built-in Radeon, or `cpu`, is a **fail**.
2. Download **Whisper large-v3 turbo** (or Whisper small). Choose its **graphics card**
   option.
   - Technical details → backend should read `vulkan:Vulkan… (AMD Radeon RX 9070 XT)`. The
     built-in Radeon or `cpu` is a **fail**.
3. For each: record load time, RAM and graphics memory the app shows after its automatic
   measurement.

## 3. Processor (CPU) model selection

1. Choose the **processor** option of Parakeet v2 → "Ready", backend `cpu`.
2. Choose **Moonshine Streaming small** (processor only) → "Ready".

## 4. Memory / VRAM reporting

While a graphics-card variant is loaded:

1. Task Manager → Details → add the "Dedicated GPU memory" column (or Performance → GPU 1
   and GPU 2). Find `aural-stt-onnx.exe` (Parakeet) or `aural-stt-ggml.exe` (Whisper).
2. Expected: the dedicated memory sits on the **RX 9070 XT**, roughly matching the app's
   "graphics memory" figure (Parakeet ~1–1.5 GB, Whisper turbo ~1.3 GB on the reference
   PC). Memory on the built-in Radeon instead is a **fail**.

## 5. Real dictation (each variant from sections 2 and 3)

1. Open Notepad. Hold **Ctrl + Win**, say: *"The quick brown fox jumps over the lazy dog.
   Please send the quarterly report to Maria by Friday."*, let go.
2. Expected: the text appears once in Notepad; the pill shows listening → a brief
   processing → success.
3. Record: was the text right, and how long from letting go to text (rough is fine).

## 6. Live transcription

General → **Show words while I speak** must be on.

1. **Parakeet (graphics card and processor):** dictate two sentences with a short pause.
   Words appear above the pill while you speak; grey words may change; they settle at the
   pause. The final text is typed **once** when you let go (no duplicates, nothing
   missing).
2. **Moonshine Streaming small:** same. Words should follow your speech continuously
   (native streaming).
3. **Long dictation:** Toggle mode (General → How the hotkey works → Toggle), speak for
   about 90 seconds with normal pauses, press again. The whole text must arrive, including
   the last sentence.
4. **Cancel:** start dictating, press **Esc**: the caption disappears, nothing is typed.
5. **Too short / silence:** tap the hotkey briefly; and hold it without speaking for 3 s.
   Nothing is typed.
6. General → the live-text line should describe the current model correctly: Moonshine
   Streaming "as you speak"; Parakeet/Whisper "settle at each short pause"; a slow model
   "too slow on this PC".

## 7. Graphics card fallback

Aural must never leave you without dictation when the graphics card fails.

- Watch during all of the above: if any graphics-card variant fails to start, Aural should
  switch to the processor option by itself and say so in a notice at the top of the
  window. Record the notice text if it appears.
- Optional, only if your monitor is connected to the **motherboard** (built-in Radeon)
  output: Device Manager → Display adapters → AMD Radeon RX 9070 XT → Disable, then start
  Aural with a graphics-card variant selected. Expected: a notice, processor variant
  active, dictation works. Re-enable the card afterwards. Skip this if your monitor is
  on the RX 9070 XT (the screen would go dark).

## 8. Writing / History (quick)

1. Writing → Tidy up: Light. Dictate "um so the meeting is at 3pm". Expected: "So the
   meeting is at 3pm".
2. Optional: Writing → Download the writing helper (793 MB), Tidy up: AI, dictate the same.
   Numbers must be unchanged.
3. History shows the dictations; Delete all; restart Aural (tray → Quit, start again);
   History stays empty.
