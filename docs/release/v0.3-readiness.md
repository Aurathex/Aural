## What's new

- **UI:** one scroll area in settings (sr-only spans had escaped the content pane and
  stretched the page into blank space); Aurathex on the About page; new Writing and
  History pages. Checked at 720×520, 820×580 and 1280×800: no page scroll, horizontal
  overflow or clipped content on any page.
- **Live transcription (B):** words above the pill while you speak; native streaming for
  Moonshine Streaming tiny/small (new, MIT), phrase-by-phrase for Parakeet and Whisper
  (a documented limitation); final text typed once; any live failure falls back to the
  v0.2 path.
- **Text pipeline (C):** dictionary, Light and AI tidy-up (off by default), per-app
  settings. AI tidy-up uses a 793 MB local model downloaded only on request, and its
  answers are used only if they keep exactly the dictated words and every number, link
  and code token.
- **Local data (D):** searchable history (text only, 30 days by default, deletable),
  statistics (numbers only), learning suggestions from your own corrections (applied only
  when you add them).

## Known limitations

- Phrase mode re-reads the phrase being spoken (not true streaming); words settle at
  pauses and phrase boundaries can change capitals or punctuation vs one whole read.
- Moonshine Streaming's final text is slower on long dictations (decoder re-reads the
  encoded audio): 2.6 s after an 11 s sentence on this processor for "small".
- AI tidy-up only fixes punctuation, capitals, hesitations and stutters (the check
  refuses any word change); it runs on the processor (about 1 s per sentence here).
- Per-app settings use the program file of the window in front when you stop; apps in
  a remote session or browser tabs aren't told apart.
- Statistics days are UTC days.
- Unsigned installer (SmartScreen warning), as for v0.2.
