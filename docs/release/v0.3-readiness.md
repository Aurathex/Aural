## What's new

- **UI:** one scroll area in settings (sr-only spans had escaped the content pane and
  stretched the page into blank space); Aurathex on the About page; new Writing and
  History pages. Checked at 720×520, 820×580 and 1280×800: no page scroll, horizontal
  overflow or clipped content on any page.
- **Live transcription (B):** words above the pill while you speak; native streaming for
  Moonshine Streaming tiny/small (new, MIT), phrase-by-phrase for Parakeet and Whisper
  (a documented limitation); final text typed once; any live failure falls back to the
  v0.2 path.
- **Text pipeline (C):** dictionary, Light and AI tidy-up (off by default), per-app
  settings. AI tidy-up uses a 793 MB local model downloaded only on request. By default
  its answers are used only if they keep exactly the dictated words and every number,
  link and code token; two opt-in switches let it improve wording and rewrite numbers
  (links, addresses, paths and code always stay exact).
- **Local data (D):** searchable history (text only, 30 days by default, deletable),
  statistics (numbers only), learning suggestions from your own corrections (applied only
  when you add them).

## Known limitations

- On AMD, DirectML (Parakeet on the graphics card) was not reported separately; Vulkan
  (Whisper) and the processor were confirmed.
- **No cloud:** no cloud transcription and no cloud AI tidy-up; everything runs on the PC.
- Moonshine Streaming is the native streaming implementation; Parakeet and Whisper live
  text is phrase-by-phrase.
- If the microphone is unplugged mid-dictation, what was recorded so far is transcribed
  and typed (as in v0.2); there is no separate "microphone lost" message.

- Phrase mode re-reads the phrase being spoken (not true streaming); words settle at
  pauses and phrase boundaries can change capitals or punctuation vs one whole read.
- Moonshine Streaming's decoder re-reads the phrase for each update, so its final text
  arrives later than Parakeet's (2.6 s after an 11 s sentence for "small" on this
  processor); streams are closed at pauses so this stays bounded per phrase.
- By default AI tidy-up only fixes punctuation, capitals, hesitations and stutters (the
  check refuses any word change) unless the wording or numbers switch is on; it runs on
  the processor (about 1–1.5 s per sentence here).
- Per-app settings use the program file of the window in front when you stop; apps in
  a remote session or browser tabs aren't told apart.
- Statistics days are UTC days.
- With "Let AI improve wording" on, the AI may change meaning slightly (seen once in 20:
  "when I rotate" → "when you rotate"); the switch says so. Off by default.
- AI tidy-up cannot fix a misheard word, and a refused answer keeps Light's text (names
  stay lowercase, e.g. "Tell john").
- If the clipboard holds data Aural cannot copy (rare handle-only formats, or over 64 MB),
  Aural types instead of pasting; Windows 11 Notepad may drop characters then.
- Unsigned installer (SmartScreen warning), as for v0.2.
