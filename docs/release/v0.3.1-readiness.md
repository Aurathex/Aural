# Aural 0.3.1 candidate validation

## Cohere Transcribe: local English transcription

The model catalog now includes Cohere Transcribe 03-2026, INT4, using the
[cstr ONNX conversion](https://huggingface.co/cstr/cohere-transcribe-onnx-int4)
of [Cohere Labs' model](https://huggingface.co/CohereLabs/cohere-transcribe-03-2026).
Inference runs locally in the ONNX speech worker on the processor. The adapter
uses an English prompt, so only English is advertised. DirectML, Vulkan and CUDA
are rejected for this export; no GPU support is claimed. There is no cloud
inference fallback.

The five download files total 1,994,857,346 bytes, including both external weight
files and the vocabulary. Every file is pinned to revision
`2c870f89692c61348481884eb6e1222ec3ba25c9`, with an independently verified SHA-256
and byte count in the catalog. The model attribution and Apache 2.0 license
link are included. The catalog requires 8 GB RAM and contains no unmeasured
speed or accuracy reference. Recordings are decoded in successive windows of
at most 30 seconds to bound encoder memory; word boundaries at window cuts
can affect long-recording accuracy.

### Verification on 2026-11-04

The optimized ONNX worker loaded the actual downloaded model through the same
worker protocol used by the app. Three bundled LibriSpeech evaluation clips
were decoded consecutively in one process:

| Clip | Decode time | Normalized word error rate |
|---|---:|---:|
| 1089-134686-0000 | 2,864 ms | 0.0 |
| 121-127105-0022 | 1,435 ms | 0.0 |
| 1320-122617-0020 | 2,456 ms | 0.0 |

The test also confirmed the reported CPU backend and empty-input behavior.
Total test duration, including load, was 9.11 seconds. These three clips are a
smoke test, not a general accuracy benchmark. Live microphone dictation and
long recordings were not established by this test.

Reproduction after downloading the pinned model:

```powershell
$env:AURAL_TEST_COHERE_DIR = '<model directory>'
cargo test -p aural-stt-onnx --test real_model worker_transcribes_cohere_real_speech --release --locked -- --ignored --nocapture
```

Additional checks passed: 2 targeted Cohere adapter tests (unsupported backend
and incomplete model download), all 85 `aural-models` tests, and
`cargo clippy -p aural-stt-onnx --tests --locked -- -D warnings`.


### Selected-text document identity limit

AI touch-up displays the original window caption before Apply. Delivery checks the
original process/window, focused control, window caption, accessibility identity
when available, and exact selected text. Generic applications can reuse all these
identifiers across documents. If a different document has the same caption,
focused-control identity and selected text, Aural cannot distinguish it from the
original document. These checks reduce accidental replacement; they do not prove
absolute document identity. Keep the original document open and verify the target
caption and revision before Apply. Do not switch documents while a preview is open.

Manual acceptance: hide a review preview, press Ctrl + Alt + T again, and verify
that the same preview reopens. Verify the original window caption in that preview.

## Final local release checks

On 2026-11-04, frozen source passed formatting, strict Clippy for the default
workspace and app, 366 default Rust tests and 77 app tests. The default suites
were unfiltered and run serially: no SignalRGB tests were excluded. Existing
ignored hardware/subprocess fixtures remain explicitly ignored in default runs.
Frontend: 55 tests pass; Svelte reports zero errors and zero warnings; production
build passes. Dependency advisories/licenses/sources policy passes, with only
existing duplicate-version and unused-allowance warnings.

SignalRGB remained running. The complete platform suite passed 62/0/10 ignored.
Explicit native fixtures also passed selected-text capture/replacement, exact
replacement once, clipboard restoration, stale-selection/wrong-field rejection,
and Windows Terminal exact-content delivery/recovery. Unknown clipboard readers
produce an honest unconfirmed status, not a second paste or false acknowledgement.

An actual local Qwen writing worker corrected two connected paragraphs while
preserving the paragraph break and protected number in 1.97 seconds. This is a
functional smoke test, not a general writing-quality benchmark. Apply always requires
review. Helper reload readiness, cancellation, shortcut disable/unregister, and
preview reopen handling have regression coverage.

Live microphone-to-Claude Code, broader browser/editor coverage, and long Cohere
recordings were not established by these fixtures. Terminal transport was tested
with an actual Windows Terminal raw-input fixture without executing commands.
The selected-text document-identity limitation described above remains applicable.
