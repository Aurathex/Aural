From thought to text

One shortcut. Less typing.

Download the installer from the official GitHub release, choose a microphone and speech model, then hold Ctrl + Win to dictate. The shortcut is changeable in settings.

Review text before sending it. For terminals and coding assistants, check the setup instructions for your release.

Does Aural work offline?

Speech recognition and the optional writing helper run locally after their models have been downloaded. Model downloads require internet access.

Can I modify and share Aural?

Aural 0.3.1 uses PolyForm Noncommercial License 1.0.0. Modification and sharing are allowed for permitted noncommercial purposes under the license. Commercial use requires separate permission. Each dependency and model keeps its own terms.
