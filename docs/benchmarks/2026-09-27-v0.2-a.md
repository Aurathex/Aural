# v0.2 A: every catalog variant on the reference PC

These numbers are the catalog's `reference` values. The hardware test scales them to
estimate other PCs; nothing in Aural treats any model as "best" in general.

## Setup

- PC: Intel Core Ultra 9 185H, NVIDIA GeForce RTX 4070 Laptop GPU (8 GB, driver
  617.14), Intel Arc iGPU, 15.4 GB RAM, Windows 11, on AC power.
- Build: Rust 1.98.1, transcribe-rs 0.3.11 (ONNX Runtime 1.24.2 via ort 2.0.0-rc.12,
  DirectML), whisper-rs 0.16.0 (whisper.cpp; Vulkan SDK 1.4.357.0 at build time).
- Tool: `tools/bench/scripts/run-matrix.ps1` (every variant in `manifests/catalog.v2.json`),
  one warm-up, runs one after another. Whisper uses 8 threads; ONNX Runtime sizes its own
  pool. RAM = process peak minus the decoded corpus; GPU = graphics memory the process
  held with the model loaded (DXGI).
- Corpus: LibriSpeech test-clean, the same 100 clips as the M0 baseline (every 26th
  utterance, ~8 s each, 2,111 words). WER is pooled.

The margin of error on 2,111 words is about ±0.7 points at 2.5% WER, so Parakeet v2/v3,
large-v3-turbo and Distil-Whisper are statistically close; Whisper small is a step behind,
then Moonshine base and Whisper base.

### What this PC shows

- **The graphics card is not always faster.** Parakeet on DirectML is about twice as slow
  as on the processor here (p50 596 vs 279 ms). The labels follow the measurements.
- **Large Whisper models need a graphics card.** On the processor, large-v3-turbo and
  Distil-Whisper take 13–15 s per sentence (RTF > 1, so "Too slow on this PC"); on the
  RTX 4070 through Vulkan they take about 0.3 s.
- **Vulkan makes small Whisper models very fast** (base 72 ms, small 137 ms), but they
  make more mistakes than Parakeet or the large models.
- Parakeet's p95 on the processor (~1.4 s) comes from the longest clips; the median is what
  a typical sentence feels like.

## Estimate accuracy (spec: within ±35%)

`tools/bench/scripts/check-estimates.ps1` over every variant measured on the 20 built-in
clips (the ones the hardware test uses; results in `results-v02-eval`). Each estimate is
calibrator p50 on those clips × (variant reference ÷ calibrator reference), as in
`aural_models::estimate`. Calibrators: Whisper tiny.en (Whisper models), Moonshine tiny
(ONNX on the processor), and, because no probe runs ONNX models on the graphics card, a
measured Parakeet v2 there (the app now does the same, see `hwtest::calibrations`).

| variant | calibrated by | estimated p50 ms | measured p50 ms | error |
|---|---|---|---|---|
| moonshine-base-int8@cpu | moonshine-tiny-int8@cpu | 373 | 424 | −12% |
| parakeet-tdt-0.6b-v2-int8@cpu | moonshine-tiny-int8@cpu | 317 | 352 | −10% |
| parakeet-tdt-0.6b-v3-int8@cpu | moonshine-tiny-int8@cpu | 309 | 368 | −16% |
| parakeet-tdt-0.6b-v3-int8@directml | parakeet-tdt-0.6b-v2-int8@directml | 728 | 687 | +6% |
| whisper-base.en-q8@cpu | whisper-tiny.en-q8@cpu | 632 | 772 | −18% |
| whisper-base.en-q8@vulkan | whisper-tiny.en-q8@vulkan | 79 | 86 | −8% |
| whisper-distil-large-v3.5@cpu | whisper-tiny.en-q8@cpu | 12,932 | 13,849 | −7% |
| whisper-distil-large-v3.5@vulkan | whisper-tiny.en-q8@vulkan | 309 | 316 | −2% |
| whisper-large-v3-turbo-q5@cpu | whisper-tiny.en-q8@cpu | 14,863 | 13,742 | +8% |
| whisper-large-v3-turbo-q5@vulkan | whisper-tiny.en-q8@vulkan | 322 | 326 | −1% |
| whisper-small.en-q8@cpu | whisper-tiny.en-q8@cpu | 2,186 | 2,620 | −17% |
| whisper-small.en-q8@vulkan | whisper-tiny.en-q8@vulkan | 150 | 168 | −11% |

**All 12 within ±35%** (worst −18%). Estimates on the processor run 10–18% low because the
built-in clips are a little harder for the bigger models than for the probes; that bias
is well inside the tolerance, so the cost ratio is left as is.

**Limit of this check:** references and measurements come from the same PC, so it tests
the formula and the change of clip set, not how well one PC's ratios carry to different
hardware (e.g. an AMD card or an older CPU). That needs results from other PCs; the
hardware test stores measured results next to estimates, so they can be compared once
people run it.

## Reproduce

```powershell
./tools/bench/scripts/run-matrix.ps1 -Corpus $env:USERPROFILE\aural-bench-corpus\librispeech-100\corpus.tsv `
    -Out $env:USERPROFILE\aural-bench-corpus\results-v02 -Backends cpu,directml,vulkan -TargetDir <build-dir>
./tools/bench/scripts/set-references.ps1 -Results $env:USERPROFILE\aural-bench-corpus\results-v02
./tools/bench/scripts/check-estimates.ps1 -Measured <results on the built-in clips>
```
