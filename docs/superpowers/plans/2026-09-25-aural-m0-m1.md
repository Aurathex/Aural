# PART B — IMPLEMENTATION PLAN: M0 (detailed) + M1 (task-level)

## Global Constraints
- OS: Windows 10 22H2+ and Windows 11, x64 only.
- Language scope v1: English only.
- License: `MIT OR Apache-2.0`; no GPL/AGPL/NC dependencies or model weights (cargo-deny enforced).
- Never commit model weights, runtime DLLs, audio recordings of real speech, build output, secrets, `.env`, certificates, or machine-specific config. Files >5 MB are rejected by CI.
- No network access except user-initiated downloads and manual update check; no telemetry.
- UI palette: black, white, neutral grays only; system font Segoe UI Variable.
- Rust stable pinned in `rust-toolchain.toml` (current stable at bootstrap); Node LTS; pnpm.
- Commits: Conventional Commits (`feat:`, `fix:`, `test:`, `docs:`, `chore:`, `build:`, `ci:`), one logical change each, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Feature work happens on worktree branches; `main` stays green.
- No GitHub push until you say so.

## Review Focus
1. **Hotkey released while a modifier is still physically down**: the injected Ctrl+V must not become Ctrl+Win+V or open Start. Expect clean paste. → test in M1 Task 1.5 (`modifier_guard_emits_keyups_and_mask`).
2. **Quick tap or silent recording**: nothing inserted, no "Thank you." hallucination, the pill hides quietly. → M1 Task 1.1 (`tap_under_250ms_discards`) and Task 1.3 (`silent_clip_is_empty`).
3. **Focus moved to another window between release and insertion**: never type into the wrong window; text goes to the clipboard with a notice. → Task 1.5 (`focus_changed_falls_back_to_clipboard_only`).
4. **Clipboard holds an image/file when dictating**: the user's clipboard is not destroyed; typing is used instead. → Task 1.5 (`nonrestorable_clipboard_switches_to_typing`).
5. **Worker crashes or hangs mid-transcription**: the app survives, restarts the worker, and the transcript is retried or the error surfaced; audio is not lost until retry. → Task 1.4 (`client_restarts_crashed_worker_and_retries_once`).

```rust
pub fn normalize(s: &str) -> Vec<String> {
    s.to_lowercase()
        .chars()
        .map(|c| if c.is_alphanumeric() || c == '\'' { c } else { ' ' })
        .collect::<String>()
        .split_whitespace()
        .map(str::to_owned)
        .collect()
}

#[derive(Debug, Clone, Copy, Default, PartialEq)]
pub struct WerStats {
    pub substitutions: usize,
    pub deletions: usize,
    pub insertions: usize,
    pub reference_words: usize,
}

impl WerStats {
    pub fn wer(&self) -> f64 {
        let errors = (self.substitutions + self.deletions + self.insertions) as f64;
        if self.reference_words == 0 {
            if errors == 0.0 { 0.0 } else { 1.0 }
        } else {
            errors / self.reference_words as f64
        }
    }
}

/// Levenshtein alignment over words; each cell stores (cost, subs, dels, ins).
pub fn word_errors(reference: &str, hypothesis: &str) -> WerStats {
    let r = normalize(reference);
    let h = normalize(hypothesis);
    type Cell = (usize, usize, usize, usize);
    let mut prev: Vec<Cell> = (0..=h.len()).map(|j| (j, 0, 0, j)).collect();
    for i in 1..=r.len() {
        let mut cur: Vec<Cell> = vec![(i, 0, i, 0)];
        for j in 1..=h.len() {
            let (dc, ds, dd, di) = prev[j - 1];
            let diag = if r[i - 1] == h[j - 1] { (dc, ds, dd, di) } else { (dc + 1, ds + 1, dd, di) };
            let (uc, us, ud, ui) = prev[j];
            let up = (uc + 1, us, ud + 1, ui);
            let (lc, ls, ld, li) = cur[j - 1];
            let left = (lc + 1, ls, ld, li + 1);
            cur.push(*[diag, up, left].iter().min_by_key(|c| c.0).unwrap());
        }
        prev = cur;
    }
    let (_, substitutions, deletions, insertions) = prev[h.len()];
    WerStats { substitutions, deletions, insertions, reference_words: r.len() }
}
```
